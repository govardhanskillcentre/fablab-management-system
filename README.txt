FabLab Management System

New machine costing features:
- Material Use supports machine name, machine time in minutes, machine rate/hour and automatic machine charge.
- Dashboard shows total machine time and machine charges for the selected date range.
- Product Costing includes machine cost in labour/profit calculation and final product amount.
- Existing database is migrated automatically when the app starts.
- Start_FabLab.bat starts the Flask app and opens http://127.0.0.1:5000.
